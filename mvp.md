# MVP TrustClinic

## Описание продукта

TrustClinic — веб-приложение для предварительной медицинской диагностики. Пользователь проходит опрос в формате чата и получает оценку риска с рекомендациями.

## Use Case: Прохождение медицинской диагностики

### Акторы
- Пользователь (пациент)

### Предусловия
- Пользователь зарегистрирован и авторизован в системе

### Основной сценарий

1. Пользователь открывает главную страницу
2. Пользователь нажимает кнопку "Начать диагностику"
3. Система перенаправляет на страницу входа (если не авторизован)
4. Пользователь вводит email и пароль
5. Система авторизует пользователя и перенаправляет на страницу диагностики
6. Система отображает чат-интерфейс с первым вопросом
7. Пользователь выбирает ответ из предложенных вариантов
8. Система показывает следующий вопрос
9. Шаги 7-8 повторяются до завершения всех вопросов (10 вопросов)
10. Система анализирует ответы и вычисляет уровень риска
11. Система сохраняет результат и отображает страницу с результатом
12. Пользователь видит:
    - Процент риска
    - Рекомендации
    - Возможность пройти диагностику повторно

### Альтернативные сценарии

**A1. Пользователь не авторизован**
- На шаге 6 система перенаправляет на страницу входа
- После успешного входа возвращает на страницу диагностики

**A2. Пользователь хочет посмотреть историю**
- Пользователь переходит в профиль
- Система отображает список предыдущих диагностик
- Пользователь может просмотреть детали любой диагностики

### Постусловия
- Результат диагностики сохранён в системе
- Пользователь получил рекомендации

## Функциональные требования

### FR-01: Регистрация
- Пользователь может создать аккаунт с email и паролем
- Валидация email формата
- Минимальная длина пароля — 6 символов

### FR-02: Авторизация
- Вход по email и паролю
- Сохранение сессии в localStorage
- Автоматический выход при истечении токена

### FR-03: Диагностика
- Чат-интерфейс с 10 вопросами
- Кнопки выбора ответа
- Индикатор прогресса
- Анимация набора текста ботом

### FR-04: Результат
- Расчёт риска на основе ответов
- Отображение процента риска
- Персонализированные рекомендации
- Цветовая индикация уровня риска

### FR-05: Профиль
- Отображение данных пользователя
- История диагностик
- Возможность выхода из аккаунта

## Нефункциональные требования

- Адаптивный дизайн
- Время загрузки страницы < 3 секунд
- Поддержка современных браузеров (Chrome, Firefox, Safari, Edge)
