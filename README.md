# TrustClinic

Веб-приложение для предварительной медицинской диагностики с чат-интерфейсом.

## Описание

TrustClinic позволяет пользователям пройти медицинский опрос в формате чата и получить оценку риска с рекомендациями. Приложение использует пиксельный дизайн в пастельных тонах.

## Структура проекта

- `frontend/` — основное React приложение
- `shared-components/` — библиотека переиспользуемых UI компонентов

## Технологии

- React 18
- TypeScript
- Vite
- Tailwind CSS
- React Router
- Jest + Testing Library

## Установка и запуск

### 1. Установка зависимостей

```bash
# Установка зависимостей frontend
cd .\frontend\
npm install
```

```bash
# Установка зависимостей shared-components
cd .\shared-components\
npm install
```

### 2. Запуск в режиме разработки

```bash
cd frontend
npm run dev
```

Приложение будет доступно по адресу: http://localhost:5173

Shared-components подключается через alias в vite.config.ts и не требует отдельной сборки.

### 3. Сборка для продакшена

```bash
cd frontend
npm run build

cd .\shared-components\
npm run build
```
